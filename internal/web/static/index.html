The Order of Things

A distributed system you are invited to break.

Four players, nine components, every one on its own goroutine. Kill a replica mid‑game. Restart it. Bring one back subtly corrupted. The tournament still ends exactly the same way — and the corrupted one never gets back in.

That is not luck, and it is not a fixed random seed. It is that every component is a state machine fed one ordered log, so any of them can rebuild the past by replaying it — and one that rebuilds it wrong can be caught before it is trusted again. Replay as a debugger.
